内容规划方案 · v3

「假如你不小心」历史回测短视频系列

基于对 86 秒竖屏成片的逐帧拆解，输出的可复刻内容体系。v3 起确立四项铁律：一期只讲一只股票、只用折线图、坐标轴必须完整标注、优先展示长期走势。

版本 v3 一期一标的 纯折线图 完整坐标轴 区间 ≥ 12 个月

v3 四项铁律（优先级高于本文档其他内容）

  1. 一期只讲一只股票——禁止排行榜、TOP3 卡片、多股对比、并列涨幅列表；任何视图不得混合多只股票数据
  2. 只用折线图——禁止蜡烛图 / K 线 / 柱状图 / 面积图 / 成交量柱 / 均线副图，代码中已移除相关组件
  3. 坐标轴必须完整——X 轴日期 + Y 轴价格，刻度值必须实际渲染可见，轴标题齐全，禁止只画折线没数字
  4. 优先长期走势——分析区间不少于 12 个月，短期数据仅作风险提示辅助

一句话拆解结论：这条片子用「结论前置 + 时间轴推进 + 坐标轴缩放」三件事，把一个 6 年、净值从 100 万到 353 万再到 254 万的复杂曲线压进 86 秒竖屏。原片用的是折线走势图（非 K 线），本规范予以保留并强化坐标轴标注；原片的单标的叙事结构同样保留并明确为铁律 1。

01选题定位

视频中呈现的做法

标题三行公式

假如你{情绪词}          ← 第1行，不确定性钩子
{年份}年买{金额}{品类}    ← 第2行，具体到可复现
{动作}{持有期}           ← 第3行，行为承诺

情绪词用的是「不小心」——不是「贪心」「冲动」这类贬义词，而是把赚到的钱归因于运气而非能力。这是整条片子的隐性观点，也是它区别于同类内容的地方。

参数化程度

年份（2020）、金额（100万）、品类（黄金）、期限（6年）四个变量全部显式暴露在标题上，观众一眼就知道讲什么，且能自行代入。

目标受众

财经内容泛受众。不是投资者，是被投资内容教育过的普通人——看过「黄金十年」这类叙事，但没被系统讲过一次真实曲线长什么样。

落地建议

四个正交维度做可持续角度

不要只做「换一个品类再算一遍」，母题真正的延展空间在这四维交叉里：

资产维度

黄金 / 白银 / 原油 / 沪深300 / 标普500 / 纳指 / 比特币 / 国债 / 中概互联 / 新能源车指数

持有期维度

1年 / 3年 / 5年 / 6年 / 10年 / 买在最高点后的 N 年

起点维度

历史最高点 / 历史最低点 / 某年年初 / 恐慌当日 / 议息会议当天

动作维度

一次性买入 / 定投 / 分批加仓 / 中途下车 / 只在暴跌日买

四个优先排期的强钩子

  1. 买在最高点——起点定在历史顶部，标题改「假如你不小心买在了最高点」，张力最强
  2. 中途下车——在最低点附近卖出，「假如你在最难的时候割了」
  3. 定投 vs 一次性——同资产两条曲线对照，回答「抄底到底有没有用」
  4. 同一年不同资产——起点钉死同一年，比谁更能扛

这三点是系列的立身之本，不要在后续期数里被标题党化改掉：① 归因反直觉（赚了 154% 但定性为「不小心」）；② 不美化中段（明确呈现 2022 年「横了两年」）；③ 结尾主动展示亏损面（不回停在 196.80% 的最高点）。

视频中呈现的做法

六段式叙事框架

  1. 钩子（0–3s）结果前置，一屏说完最终资产与收益率
  2. 起点（3–8s）买入当下，收益率极低甚至微亏，建立「这不是好事」的直觉
  3. 磨底（8–32s）长时间停滞/回撤，最关键的一段，建立「长期很难熬」认知
  4. 主升（32–58s）收益率陡峭上行，回报感最强，配宏观事件解释
  5. 高点（58–78s）收益峰值，画面出现「主升浪」标签
  6. 回落+收尾（78–86s）冲顶回撤，落到期末真实值，回到开头数字闭环

最精巧的设计：数字闭环

结尾的 154.12% / 254.12 万，与开头钩子的数字完全一致。观众在 3 秒时知道了答案，86 秒后再回到这个答案时，感受已经从「哦」变成「原来中间这么难熬」。

落地建议

时长配比标准

模块占比依据
钩子3–5%竖屏信息流只有 1.5 秒决定是否划走，必须一屏说完
起点5–10%越快越好，建立「起投即低点」的反差
磨底25–30%不可压缩，这段决定内容可信度
主升25–30%回报感与信息密度峰值区

回落收尾10–15%决定内容的诚实度与可信度

核心比例原则：磨底 : 主升 ≈ 1:1。只讲主升就是宣传，只讲磨底就是劝退，1:1 才有「值」的感觉。

刻度步长归整算法

避免出现 37.14% 这类刻度，归整到 1/2/5/10 的整数倍：

function niceTicks(lo, hi, count = 5) {
  const raw = (hi - lo) / count;
  const mag = Math.pow(10, Math.floor(Math.log10(raw)));
  const n = raw / mag;
  const step = (n >= 5 ? 10 : n >= 2 ? 5 : n >= 1 ? 2 : 1) * mag;
  const start = Math.ceil(lo / step) * step;
  const out = [];
  for (let v = start; v <= hi + step * 1e-6; v += step) out.push(v);
  return out;
}

建议上画面的 3 个：总收益率（主数字）· 含息年化收益率（字幕第二行小字）· 最大回撤（结尾段必须出现）。

新增说明（v2，来自茅台实测）：A 股标的长期持有时，分红对结论影响极大。茅台 2020-01 买入至 2026-09，不含息总收益率 58.61%，含息后为 91.29%，年化从 7.16% 提升到 10.15%。若视频只用不含息口径，会系统性低估 A 股长期持有价值。因此 A 股标的必须计算并展示含息口径，同时明确标注是否含息。

另需注意：回测起点若恰为区间最低点（本例 2020-01-23 即为区间最低），最大浮亏会显示为 −0.00%，须在画面说明「买入当日即为区间最低点」，否则观众会质疑数据真实性。

节点筛选规则（固化为算法）

  1. 起点：回测起始日，或距起点最近的极值日
  2. 阶段极值：按 12 个月窗口取窗口内极值（不建议用 3–6 个月，实测会导致节点数超标）
  3. 大拐点：相对 6 个月前涨跌幅 > 12%
  4. 宏观/事件日：央行议息、CPI 发布、财报披露、重大政策日
  5. 终点：数据截止日，必须选

合并收敛规则（v2 新增，必做）

  • 相邻节点间隔 ≤ 2 个月视为同一段，只保留该段中资产值最高/最低的那个
  • 若合并后仍多于 12 个，按「距前 6 个月的波动幅度」降序取前 10 个，起点与终点强制保留
  • 校验器必须硬性拦截：节点数不在 8–12 区间直接判定「需重筛」

说明：茅台实测首轮按 6 个月窗口筛出 29 个节点，超出区间；加入合并收敛后落至 9 个，符合规范。

风险提示三层呈现（全保留）

  • 常驻层——底部合规条全程可见
  • 节点级——事件卡主动写出回撤数值（−30.52%）
  • 标签级——阶段标签本身带情绪词（「冲顶后回落」）

模板 A · 回测主脚本

import pandas as pd, numpy as np

def backtest(prices, initial=1_000_000):
    shares = initial / prices.iloc[0]        # 份额口径
    nav = prices * shares                        # 净值序列
    ret = nav.pct_change().dropna()

    years      = (nav.index[-1] - nav.index[0]).days / 365.25
    total_ret  = nav.iloc[-1] / initial - 1
    cagr       = (nav.iloc[-1] / initial) ** (1/years) - 1
    drawdown   = (nav - nav.cummax()) / nav.cummax()
    mdd        = drawdown.min()

    return {
        "总收益率":   f"{total_ret:.2%}",
        "年化收益率": f"{cagr:.2%}",
        "最大回撤":   f"{mdd:.2%}",
        "年化波动率": f"{ret.std()*np.sqrt(252):.2%}",
        "正收益日占比": f"{(ret>0).mean():.1%}",
    }

def pick_nodes(nav, window="90D", min_move=0.08):
    """按规则筛节点：窗口极值 + 大拐点"""
    roll_max = nav.rolling(window, min_periods=20).max()
    roll_min = nav.rolling(window, min_periods=20).min()
    extreme  = (nav >= roll_max) | (nav <= roll_min)
    pivot    = nav.pct_change(window).abs() > min_move
    return nav[extreme | pivot].resample(window).last().dropna()

三条容易被忽略的红线

  1. 「历史数据模拟」不能替代「数据来源标注」——前者是免责声明，后者是溯源要求，两者都要有
  2. 回撤数字必须可复算——观众会去核对，错了比不做更伤
  3. 宏观归因不可编造——「因为降息所以涨」这类表述要基于真实时间线，否则涉嫌虚假信息
