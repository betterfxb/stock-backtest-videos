## ⚠️ 最高优先级铁律（任何制作动作前必读）

> 这一节的五条约束优先级高于本文档其他所有内容。与其他章节冲突时，以本节为准。

### 铁律 1 · 一期只讲一只股票

- 每期视频**只分析一只标的**，从选题到结尾不得出现第二只股票
- **禁止**排行榜、TOP3 卡片、多股对比折线、并列涨幅列表
- **禁止**在同一视图中混合多只股票的数据系列
- 多标的横向对比**不属于本系列**，如需对比另立系列

**理由**：单标的才能讲透一条完整曲线。多股混排会让观众注意力分散，既看不清趋势，也记不住内容。

### 铁律 2 · 只用折线图，禁止一切 OHLC 类图形

- **唯一允许的图表形式是折线图**（面积图允许，但须与折线图二选一，不可叠加）
- **禁止**蜡烛图 / K 线 / 柱状图 / 成交量柱
- 已在代码中**移除** `Candles` 组件及相关均线逻辑，`components.tsx` 仅保留 `TrendChart`

**理由**：K 线在竖屏短视频中每个蜡烛宽度不足 6px，形态完全无法辨认，只会产生视觉噪音。面积图在竖屏中可展示累计收益概念，但不可与折线图叠加，避免视觉混乱。

### 铁律 3 · 折线图必须同时标注两个坐标轴

折线图**必须**且**同时**包含：

| 要素 | 要求 |
|---|---|
| **X 轴（日期）** | 5–6 个刻度，格式 `MM-DD`，首尾刻度**必须**显示年份（`2026-07`） |
| **Y 轴（价格）** | 4–5 个刻度，刻度**数值必须实际渲染可见**，不可只画网格线 |
| **轴标题** | X 轴标「日期」，Y 轴标「价格（元）」或「累计涨跌幅」 |
| **基准线** | 价格模式标注买入成本，涨跌幅模式标注 0% 零轴 |

**禁止**：只有折线没有刻度值、只有网格线没有数字、刻度值被裁切。

### 铁律 4 · 优先展示长期走势

- 分析区间**不少于 12 个月**，优先 2–3 年
- 叙事主轴是**长期趋势**，不是日内或数日波动
- 短期数据（5 日 / 20 日）仅作为「风险提示」段的辅助，不占主图

### 铁律 5 · 折线图两种模式服务于同一只票

允许在同一视图内切换，但**标的始终是同一只**：

| 模式 | Y 轴内容 | 用途 | 实现状态 |
|---|---|---|---|
| `price` 价格模式 | 实际收盘价（元） | 讲「价格怎么走」 | ✅ 已实现 |
| `change` 涨跌幅模式 | 以首日为 0% 的累计涨跌幅 | 讲「相当于涨了多少」 | ✅ 已实现（见 §3.0 示例） |

切换是同一只标的的两种表达方式，**不构成多标的混合**。

## 0. 拆解结论速览（一句话讲清它为什么成立）

这条片子用「**结论前置 + 时间轴推进 + 坐标轴缩放**」三件事，把一个 6 年、跨度 250 万到 353 万的复杂资产曲线，压进 86 秒竖屏里，且全程无口播、无出镜、无引导关注。

> **v3 说明**：原片使用的是折线走势图（非 K 线），本规范予以保留并强化坐标轴标注；原片的单标的叙事结构同样保留并明确为铁律 1。


| 维度 | 视频中呈现的做法 |
|---|---|
| 选题形态 | 假设句式（"假如你不小心"）+ 具体年份 + 具体金额 + 具体品类 + 明确持有期 |
| 叙事引擎 | 时间轴逐段推进，每个节点配一张宏观事件卡 |
| 视觉锚点 | 标题三行、右上收益率、游标标签、合规条 —— 四层全程不变 |
| 数据呈现 | 折线图 + 动态 Y 轴 + 虚线趋势基准 + 端点气泡标注 |
| 情绪曲线 | 涨 → 跌回个位数 → 长期停滞 → 陡峭主升 → 冲顶回落 |
| 收尾方式 | 用最大回撤收尾，不做引导关注 |

## 1. 选题定位

### 1.1 视频中呈现的做法

**主题**：单资产、长时间跨度、指定持有期的历史持有收益回测。

**标题模板（固定三行结构）**：
```
假如你{情绪词}          ← 第 1 行，不确定性钩子
{年份}年买{金额}{品类}    ← 第 2 行，具体到可复现
{动作}{持有期}           ← 第 3 行，行为承诺
```
情绪词用的是「不小心」——不是「贪心」「冲动」这类贬义词，而是**把赚到的钱归因于运气而非能力**。这一点很关键，见 §1.3。

**参数化程度极高**：年份（2020）、金额（100万）、品类（黄金）、期限（6年）四个变量全部显式暴露在标题上，观众一眼就知道这条片子讲什么，且能自行代入。

**目标受众**：财经内容泛受众。不是投资者，是**被投资内容教育过的普通人**——他们看过"黄金十年""通胀时代"这类叙事，但没被系统讲过一次"真实曲线长什么样"。

### 1.2 可持续的内容角度

这条母题可拆出的角度不是"换一个品类再算一遍"，而是**四个正交维度**：

| 维度 | 取值 | 差异点 |
|---|---|---|
| 资产 | 黄金 / 白银 / 原油 / 沪深300 / 标普500 / 纳指 / 比特币 / 国债 / 原油股 / 房地产 | 单资产横向对比 |
| 持有期 | 1年 / 3年 / 5年 / 6年 / 10年 / 买在最高点 | 期限敏感性 |
| 起点 | 历史最高点 / 历史最低点 / 某年年初 / 某年年中 / 恐慌当日 | **买在高点**是最强钩子 |
| 动作 | 一次性买入 / 定投 / 分批加仓 / 拿了又卖 / 中途下车 | 行为差异 |

**三个能直接复用的强角度**（建议优先排期）：

1. **买在最高点**：把起点定在历史顶部（如 2021 年黄金顶部、2020 年茅台顶部），标题改为"假如你不小心买在了最高点"
2. **中途下车**：在最低点附近卖出，标题改为"假如你在最难的时候割了"
3. **定投 vs 一次性**：同一资产两条曲线对照，回答"抄底到底有没有用"（**注**：此角度涉及双曲线对照，需另立「对比专题」系列，不并入本系列）

> **v3.1 清理**：删除「同一年不同资产」角度（违反铁律 1 单标的约束）。

### 1.3 差异化价值

**视频用三处设计建立了差异化**：

- **归因反直觉**：赚了 154% 却被定性为"不小心"。这条片子的隐含观点是「**长期持有本身就是一种运气，收益率不等于能力**」。这与市面上一律归因于"因为你看准了"的叙事完全相反。
- **不美化中段**：明确呈现 2021–2022 年收益率跌到 8.50%、"横了两年"。多数同类内容会剪掉这段。
- **结尾主动展示亏损面**：最终落在 −30.52% 最大回撤、期末从 353.10 万回落到 254.12 万，而不是停在 196.80% 的最高点。

**建议保留并强化**：这三点是这个系列的立身之本，不要在后续期数里被"标题党化"改掉。

## 2. 内容结构

### 2.1 视频中呈现的时间轴分配

总时长 86.07 秒，实测各段落如下：

| 时间 | 时长占比 | 模块 | 画面内容 |
|---|---|---|---|
| 0–3s | 3.5% | **钩子** | 大字报：假如 2020 年买入 100 万黄金 / 最终资产 254.12 万 / 154.12%，底部缩略全曲线预告 |
| 3–14s | 12.8% | 起投即震荡 | 收益率 7.15%（2020-03-05，107 万）→ 23.84%（2020-07-27，124 万） |
| 14–32s | 20.9% | 回撤至个位数 | 12.38%（2021-01-20）→ 9.70%（2021-07-16，110 万）→ 8.50%（2022-07-11） |
| 32–58s | 30.2% | 趋势确立 | 31.34%（2023-07-27，131 万）→ 63.63%（2024-08-19，164 万）→ 123.20%（2025-04-15，223 万） |
| 58–78s | 23.3% | 主升浪加速 | 170.23%（2025-12-08，270 万）→ 196.80%（2026-04-08，297 万） |
| 78–86s | 9.3% | 冲顶回落 + 结论 | 154.12%（2026-09-28，254 万），最大回撤 −30.52% |

### 2.2 单期叙事框架（可变序六段式）

根据标的走势特征，六段式允许两种叙事引擎：

**A 型（磨底 → 主升）**：适合「买在低点、长期持有后起飞」的标的（如黄金）

```
① 钩子        0–3s     结果前置，一句话说完最终资产与收益率
                          ↓ 抛出隐含疑问：凭什么？
② 起点        3–8s     买入当下，收益率极低甚至微亏（建立"这不是好事"的直觉）
③ 磨底        8–32s    长时间停滞/回撤（最关键的一段，建立"长期很难熬"认知）
④ 主升        32–58s   收益率陡峭上行（回报感最强，配宏观事件解释）
⑤ 高点        58–78s   收益峰值，画面出现"主升浪"标签
⑥ 回落+收尾   78–86s   冲顶回撤，落到期末真实值，回到开头的数字闭环
```

**B 型（主升 → 磨底）**：适合「买在高点、长期套牢」的标的（如茅台）

```
① 钩子        0–3s     结果前置，一句话说完最终资产与收益率
                          ↓ 抛出隐含疑问：凭什么？
② 起点        3–8s     买入当下，收益率极低甚至微亏（建立"这不是好事"的直觉）
③ 主升        8–20s    早期上涨（建立"一开始是赚的"错觉）
④ 冲顶        20–25s   收益峰值，画面出现"见顶"标签
⑤ 长期磨底    25–75s   长时间停滞/回撤（最关键的一段，建立"长期很难熬"认知）
⑥ 收尾        75–86s   弱反弹或继续下跌，落到期末真实值，回到开头的数字闭环
```

**闭环设计**：结尾的 154.12% / 254.12 万，与开头钩子的数字**完全一致**。这是这个结构最精巧的地方——观众在 3 秒时知道了答案，86 秒后再回到这个答案时，感受已经从"哦"变成"原来中间这么难熬"。

### 2.3 各模块的时长占比建议

| 模块 | 占比 | 依据 |
|---|---|---|
| 钩子 | 3–5% | 竖屏信息流只有 1.5 秒决定是否划走，必须一屏说完 |
| 起点 | 5–10% | 越快越好，建立"起投即低点"的反差 |
| 磨底 | **25–30%** | 不可压缩。这段决定了内容的可信度 |
| 主升 | **25–30%** | 回报感与信息密度峰值区 |
| 高点 | 15–20% | 峰值展示，不可省略 |
| 回落收尾 | 10–15% | 决定内容的诚实度与可信度 |

**核心比例原则**：**磨底与主升均不可省略**，比例因标的而异，不强制 1:1。只讲主升就是宣传，只讲磨底就是劝退，两段都有才有"值"的感觉。

**刻度步长归整算法**（避免出现 37.14% 这类刻度）：

```python
def nice_ticks(lo, hi, count=5):
    raw = (hi - lo) / count
    mag = 10 ** floor(log10(raw))
    norm = raw / mag
    step = (10 if norm >= 5 else 5 if norm >= 2 else 2 if norm >= 1 else 1) * mag
    start = ceil(lo / step) * step
    return [round(v, 2) for v in arange(start, hi + step, step)]
```

**X 轴标签策略**（避免拥挤与歧义）：

| 位置 | 格式 | 字重 |
|---|---|---|
| 首刻度 | `2026-07`（含年） | 700 |
| 尾刻度 | `2026-09`（含年） | 700 |
| 中间刻度 | `07-24`（月-日） | 400 |
| 跨年时 | 全部刻度含年份 | — |

### 3.1 视频中呈现的数据种类

视频实际用到的数据只有三类，但组合方式有讲究：

| 数据种类 | 在视频中的呈现 | 作用 |
|---|---|---|
| **资产净值曲线** | 粉色折线，纵轴为"XX 万" | 主叙事线 |
| **收益率序列** | 右上角大号数字 + 日期 | 情绪计 |
| **宏观事件标签** | 左下事件卡：日期 · 类型 + 数字标题 + 解释 | 因果归因 |

事件卡实测文案（用于理解句式）：

```
2020年8月 · 上涨 / 最高 129.85 万
疫情后全球央行大放水、实际利率转负，金价创出历史新高，
2020 年 8 月 7 日资产摸到 129.85 万。

2022年3月 · 横盘 / 还在 120.50 万
疫苗落地、美元走强、美联储转鹰，2021 全年几乎原地踏步，
到 2022 年 3 月 9 日资产仍在 120.50 万。

2024年10月 · 上涨 / 最高 182.17 万
美联储进入降息周期、美元回落，黄金 ETF 持续吸金，
2024 年 10 月 30 日资产涨到 182.17 万。

2026年7月 · 回撤 / 从 353.10 万跌到 245.33 万
2026 年 1 月 29 日冲上区间最高 353.10 万后掉头向下，
7 月 1 日只剩 245.33 万，最大回撤 −30.52%；期末 254.12 万。
```

**事件卡的固定句式**：`日期 · 类型` / `一句话数字结论` / `宏观原因 + 具体日期 + 资产数值`。

左上方另有一枚**阶段标签**（小圆点 + 标题 + 一行注解），实测取值：
- 放水推新高 / 避险与流动性一起涌进来
- 横了两年 / 涨完之后是漫长的原地走
- 降息交易 / 实际利率下行打开空间
- 主升浪 / 一年涨掉前面五年
- 冲顶后回落 / 最高点下来，回撤三成

### 3.2 建议补充的指标体系

视频只用"收益率"一个指标，这既是它的简洁之处，也是它的短板。建议在**不破坏简洁**的前提下，内部建完整指标表，视频上只呈现 3 个：

**内部必算（不出现在画面）**：

| 指标 | 公式 | 用途 |
|---|---|---|
| 总收益率 | `(期末 - 初始) / 初始` | 视频主数字 |
| **含息总收益率** | `(期末市值 + 累计分红 - 初始) / 初始` | **A 股必备**，见下方说明 |
| **含息年化收益率** | `(含息总资产/初始)^(1/年数) - 1` | 跨期对比的唯一可比口径 |
| 年化收益率 | `(期末/初始)^(1/年数) - 1` | 不含息口径，须标注 |
| 最大回撤 MDD | `min((P_t - P_s)/P_s)` | 视频已用，做完整性校验 |
| 回撤区间时长 | 从前高到前低的天数 | 判断"难受了多久" |
| 最大回撤修复天数 | 从前低回到前高的天数 | 判断"回本有多难" |
| 波动率（年化） | `std(日收益率) × √252` | 衡量持有体验 |
| 最大浮亏 | `min(P_t/初始 - 1)` | 观众最真实的痛点 |
| 持有正收益占比 | 上涨交易日数 / 总交易日数（按实际数据频率，日频/月频） | 解释"为什么拿不住" |
| 累计分红 | 逐次除息日派息 × 持股数 | A 股长期持有的关键变量 |

> **v3.1 补充**：
> - 非分红标的（黄金、原油、ETF 等）只展示不含息口径，不计算含息指标
> - 若最大浮亏 ≈ 0%（起点即最低点），改为展示「买入后最大回撤」或「区间最大回撤」
> - 分红口径统一为「现金到账」，画面标注「分红未再投资」

> **新增说明（v2，来自茅台实测）**：A 股标的长期持有时，**分红对结论影响极大**。茅台 2020-01 买入至 2026-09，不含息总收益率 58.61%，含息后为 **91.29%**，年化从 7.16% 提升到 **10.15%**。若视频只用不含息口径，会系统性低估 A 股长期持有价值。因此 A 股标的**必须计算并展示含息口径**，同时明确标注是否含息。
>
> 另需注意：回测起点若恰为区间最低点（本例 2020-01-23 即为区间最低），最大浮亏会显示为 −0.00%，须在画面中说明「买入当日即为区间最低点」，否则观众会质疑数据真实性。

**建议上画面的 3 个**：
1. **总收益率**（主数字，必须有）
2. **年化收益率**（字幕第二行，小字，帮助跨期对比）
3. **最大回撤**（结尾段必须出现）

### 3.3 筛选逻辑（选哪一天作为叙事节点）

视频的节点不是等间隔的，而是**按"宏观事件 + 资产特征值"双条件挑的**。实测节点分布：

```
2020-03-05  107 万   起投点附近
2020-07-27  124 万   阶段高点
2021-01-20  ~114 万  阶段低值
2021-07-16  110 万   回撤后
2022-07-11  ~108 万  磨底区间
2023-07-27  131 万
2024-08-19  164 万
2025-04-15  223 万
2025-08-12  219 万   阶段低值
2025-12-08  270 万
2026-04-08  297 万   区间高点
2026-09-28  254 万   期末
```

**节点筛选规则（建议固化为算法）**：
1. **起点**：回测起始日；若起始日非区间极值，则补充最近的区间极值日作为第 2 节点
2. **阶段高点/低点**：按 **滚动 12 个月窗口**取窗口内极值（**不建议用 3–6 个月**，实测会导致节点数超标）
3. **大拐点**：满足「相对 **12 个月前**涨跌幅 > 12%」的日期
4. **宏观事件日**：央行议息（美联储 FOMC 会议日）、CPI 发布、财报披露（公司公告日）、重大政策日；可从 `westock news` 接口按关键词筛选
5. **终点**：数据截止日，必须选

**合并收敛规则（必做）**：
- 相邻节点间隔 ≤ 2 个月视为同一段，**只保留该段中资产值最高或最低的那个**（取极值）
- 若合并后仍多于 12 个，按「距前 **12 个月**的波动幅度」降序取前 10 个，起点与终点强制保留
- **校验器必须硬性拦截**：节点数不在 8–12 区间直接判定「需重筛」

### 4.2 关键卡点（必须人工确认的 5 处）

1. **数据源确认** — 期初数据的来源、口径、是否复权，书面记录
2. **异常值确认** — 单日涨跌幅 > 30% 或单月涨跌幅 > 50% 时必须查证（可能是数据错误而非真实行情）
3. **回撤数字确认** — 视频上写的回撤是观众最会核对的数字，错一次毁信任
4. **事件真实性** — 宏观事件的日期与表述必须真实，不能编造因果
5. **合规声明位置** — 必须全程可见，不能只在片尾出现

### 5.2 可复用分析模板

**模板 A：回测主脚本骨架**

```python
import pandas as pd
import numpy as np

def backtest(prices: pd.Series, initial: float = 1_000_000):
    """输入：日频收盘价序列；输出：净值、全部指标"""
    shares = initial / prices.iloc[0]          # 份额口径
    nav = prices * shares                       # 净值序列
    ret = nav.pct_change().dropna()

    years = (nav.index[-1] - nav.index[0]).days / 365.25
    total_ret = nav.iloc[-1] / initial - 1
    cagr = (nav.iloc[-1] / initial) ** (1 / years) - 1
    running_max = nav.cummax()
    drawdown = (nav - running_max) / running_max
    mdd = drawdown.min()
    underwater = drawdown < -1e-9
    max_underwater = underwater.sum()

    return {
        "初始资产": initial,
        "期末资产": round(nav.iloc[-1], 2),
        "总收益率": f"{total_ret:.2%}",
        "年化收益率": f"{cagr:.2%}",
        "最大回撤": f"{mdd:.2%}",
        "最长水下天数": int(max_underwater),
        "年化波动率": f"{ret.std() * np.sqrt(252):.2%}",
        "最大浮亏": f"{nav.min() / initial - 1:.2%}",
        "正收益日占比": f"{(ret > 0).mean():.1%}",
        "区间最高": f"{nav.max():,.2f}",
        "区间最低": f"{nav.min():,.2f}",
        "峰值日期": nav.idxmax().strftime("%Y-%m-%d"),
        "谷值日期": nav.idxmin().strftime("%Y-%m-%d"),
    }

def pick_nodes(nav: pd.Series, window: str = "90D", min_move: float = 0.08):
    """按 §3.3 规则筛节点：窗口极值 + 大拐点"""
    roll_max = nav.rolling(window, min_periods=20).max()
    roll_min = nav.rolling(window, min_periods=20).min()
    is_extreme = (nav >= roll_max) | (nav <= roll_min)
    is_pivot = nav.pct_change(window).abs() > min_move
    nodes = nav[is_extreme | is_pivot]
    return nodes.resample(window).last().dropna()
```

**标签避让规则（渲染实战总结）**

1. 含中文单位的数字（如「254.12 万」）必须使用 `msyhbd.ttc`，Segoe UI Bold 无法渲染中文
2. 同一密集区内的两个标签必须分置曲线上方/下方，不可同侧
3. 贴边元素须收边计算：`left = min(x, 画布宽 − 文本宽 − 边距)`
4. 大字号数字须先实测文本宽度，再反推容器尺寸，避免压出卡片

**压力测试验收标准（必做）**

交付前须将成片压至 **276 kbps**（原片同等码率）复检：所有文字仍应笔画完整、无粘连、色块干净。未通过则回退调整字重与对比度。

## 7. 合规提示

### 7.1 视频中呈现的做法（做得好的部分）

1. **合规条全程常驻**：从第 0 秒到第 86 秒，底部始终可见「历史数据模拟，切勿作为投资建议」，不是只在片尾一闪而过
2. **主动暴露亏损**：明确写出最大回撤 −30.52%、从 353.10 万跌到 245.33 万
3. **定性为"模拟"**：标题用"假如"，明确是假设情境而非预测
4. **不出现引导关注**：全片无"关注我""点赞领取"等指令

### 7.2 必须落实的合规要点

**数据引用标注**
- 视频内或简介中标注：数据来源（如"数据来源：上金所 / Wind"）
- 标注复权口径与计价方式
- 标注数据截止日期
- 宏观事件注明出处（央行公告 / 统计局数据）

**声明措辞（建议逐字采用）**
```
本视频为历史数据模拟，不构成任何投资建议。
所示收益率为历史区间模拟结果，不代表未来收益。
投资有风险，决策需谨慎。
```

**禁用词清单（脚本落地前逐一检查）**
| 类别 | 禁用词 |
|---|---|
| 承诺类 | 稳赚、保本、无风险、必涨、一定、必然、翻倍 |
| 诱导类 | 赶紧上车、最后机会、错过就没了、内幕、主力 |
| 归因类 | 教你稳赢、跟着买就赚、稳赚不赔 |
| 时点类 | 建议买入、可以入场、现在正是时候 |

**平台与监管注意事项**
- 不预测具体价格点位，不给具体买卖时点
- 不推荐具体产品（ETF 名称、基金代码）
- 涉及宏观事件归因时，只做客观陈述，不做因果推论式荐股
- 保留原始数据文件与计算脚本至少 6 个月，以备核查
- 如收到平台合规问询，须能立即提供：原始数据 + 计算过程 + 免责声明截图

**数据缺失处理规范**
- 数据不足 12 个月的标的（次新股、退市股），须标注「次新股/数据不足」，或另立「次新股专题」系列
- 数据缺失 > 5% 时，须在画面或简介中标注「部分数据缺失，已做插值处理」
- 若标的长期停牌，须标注「停牌期间数据缺失」

### 7.3 四条容易被忽略的红线

1. **"历史数据模拟"不能替代"数据来源标注"** — 前者是免责声明，后者是溯源要求，两者都要有
2. **回撤数字必须可复算** — 观众会去核对，错了比不做更伤
3. **宏观归因不可编造** — "因为降息所以涨"这类表述要基于真实时间线，否则涉嫌虚假信息
4. **亏损标的须如实呈现** — 若回测结果为负收益，标题与主数字须如实展示亏损，不得用「回撤」「调整」等词淡化
