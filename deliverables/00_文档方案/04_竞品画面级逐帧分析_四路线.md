# 04 竞品画面级逐帧分析（四路线）

> 方法：ffmpeg 下载原片 → 全帧场景检测（scene>0.06）→ 抽帧（2/4/1fps）→ Windows OCR（zh-Hans-CN）逐帧识别 + Python 像素统计（亮度/主色/内容覆盖率/帧差运动量）逐帧合并成时间线。
> 局限：OCR 对小字/花字有乱码；配色经 4bit/通道量化（如 #222233 实为 #222–#2F 区间桶）；美感判断仍需人工过目（模型无图像输入）。
> 日期：2026-10-06。样本 4 支，覆盖调研报告 A/B/C/D 四条路线。

## A 路线：微观商学《数据可视化》第4集·原油百年
`video/7244742686517824808` · 54.82s · 2023-06-15 · 赞5/评1（系列第1–9集，每集40–57s）

### 结构（仅 3 个切点，基本一镜到底）
| 时间 | 段落 | 帧证据 |
|---|---|---|
| 0.0–4.5s | 品牌片头：黑底 logo 动画「MIFI / 微观市场数据结构研究所 TECH WISE SAVE THE WORLD」 | 亮度14→41，运动量9–23 |
| 4.5–5.9s | 标题卡浮现「近百年原油价格走势及重大历史事件」 | 亮度回落39，切点5.87–5.93 |
| **6.0–50.8s（44.8s，占82%）** | **单一连续镜头：折线从1923画到2022** | 亮度恒定57，运动量稳态1.4–2.7 |
| 51.0–54.8s | 片尾 logo 复现 + 亮度爬升到白闪（49→145） | 切点51.2 |

### 主图表画面要素（OCR 常驻项）
- 背景 **#222233 深蓝灰**（占比41%），内容覆盖59–63%
- 顶部常驻主标题；左上「单位：美元/桶」+ **Y轴动态重标尺至少5次**（0-3 → 0-12 → 0-40 → 0-100 → 0-147 量级）
- X轴年份随画线推进（约0.44年/秒）；底部常驻「数据来源：公开数据整理」「年平均价格（美元/桶）」+ 所究所水印
- **事件注释随线到达逐个点亮**（非全量前置），全程约17个事件 ≈ 每2.6秒一个：
  1938:2.05 / 1945:1.18 数值标签（~15s）→ 1986切尔诺贝利（33s）→ 1990伊拉克入侵科威特（34.5s）→ 1991海湾战争（35.5s）→ 叶利钦石油私有化（36s）→ 1996安哥拉1365米深水油田（37s）→ 1998埃克森美孚合并（38s）→ 9·11（39s）→ 2003伊拉克战争（40s）→ **2008 WTI 147.27 历史最高+雷曼**（42s）→ 2009页岩革命（43s）→ 2010 BP墨西哥湾漏油·年均102.59（43.5s）→ 2018上海原油期货挂牌（46.5s）→ 沙特阿美IPO（47.5s）→ **2022俄乌冲突→100美元**（48.5s）
- 49.5–50.5s 定格全景（运动量降到1.9），随后切片尾

### 动效规律
- 常态运动量1.4–2.7（匀速画线，无闪烁，亮度全程恒定）
- 注释弹出尖峰3–7；转场28–35
- 弱点：**前4.5s纯品牌logo对无粉账号=劝退**，与改进清单#1（3秒倒叙钩子）判断一致

## C 路线：涨10倍股（口播快切）
`video/7472745776829975867` · 137.1s · 576×1024 HEVC（视频-only轨）· 赞425/评10

- **51个切点，平均每2.7s一切**；硬切运动量36–52，句间4–17
- **亮/暗两型画面交替形成节奏**：
  - 亮屏（亮度~145，#AAAAAA底，覆盖86%）＝白底大字结论卡/金句卡
  - 暗屏（亮度111–119，#111111底，覆盖80–86%）＝**行情软件暗色截图**，OCR可见周期栏「1分/5分/15分/30分/120分」与标的：APP、HIMS、RKLB、CVNA、Robinhood、MSTR、PLTR、VST、Sprouts Farmers、CLS天弘科技
- 结构：
  - 0–11s 钩子：2024美股走出10个十倍股 → 只看千亿以上10只 → 对挖掘A股牛股有指导意义
  - 12–120s 逐股讲解（每只约10–12s＝暗屏截图×2–3 + 亮屏金句×1–2）
  - 120–137s 总结：多数牛股受益AI；美股医药/消费股不行，主要是科技股在涨
- **烧录大字幕逐句跟读**（OCR几乎每帧变化＝卡拉OK式字幕驱动画面刷新）
- 启示：14kb/s级静态素材+快切+大字幕即可跑量；亮暗交替是免费的节奏工具
